# Luma Watch Party

Приватні кімнати спільного перегляду для 1–4 людей. Відео та аудіо передаються напряму між браузерами через WebRTC; невеликий Node.js сервер лише видає сторінку та пересилає сигнали з’єднання.

## Профіль, мобільний режим і якість

- Профіль анонімний: ім’я та випадковий ID зберігаються в `localStorage` цього браузера. Пошта й пароль не потрібні. Якщо стерти дані сайту або перейти в інший браузер, з’явиться новий профіль.
- Один профіль може бути лише одним учасником тієї самої кімнати. Повторне відкриття запрошення в іншій вкладці не додасть друге місце.
- На телефоні кнопка «Транслювати камеру телефона» надсилає відео з камери. Поверни телефон горизонтально перед запуском, якщо хочеш горизонтальне відео; плеєр на комп’ютері зберігає співвідношення сторін і не обрізає зображення.
- Захоплення екрана й камера просять браузер про 2K та 30 кадрів/с. Якщо мережі бракує, WebRTC зменшує роздільність кроками до 720p, зберігаючи верхню межу 30 кадрів/с. Пристрій, браузер або нестабільна мережа все одно можуть не втримати 30 FPS.

## Запуск

Потрібен Node.js 18 або новіший. У каталозі проєкту запустіть:

```sh
npm start
```

Відкрийте `http://localhost:3000`. Введіть ім’я, щоб створити локальний анонімний профіль. Щоб запросити друзів, натисніть «Запросити друзів» і надішліть посилання на кімнату. На комп’ютері можна поділитися вкладкою, вікном або екраном; на телефоні доступна трансляція камери.

## Розгортання

Для доступу з інтернету розгорніть Node.js сервер за HTTPS і WSS доменом: браузери дозволяють захоплення екрана лише на захищених сторінках (або localhost). Поточне WebRTC налаштоване на пряме з’єднання з публічним STUN сервером. Деякі корпоративні мережі та NAT потребують TURN сервера, який потрібно налаштувати окремо.

Застосунок не ставить таймерів або платних лімітів на перегляд. Фактична якість і затримка залежать від камери/екрана, браузерів, пристроїв і пропускної здатності мережі. Цільова якість — до 2K при 30 FPS; адаптер зменшує роздільність, щоб зберегти частоту кадрів, наскільки дозволяють пристрій і мережа.
